# honey_sdm

AI와 함께 개발하기 위한 프로젝트 저장소입니다.

## 현재 상태

- 개발 환경 연결을 위해 저장소를 초기화했습니다.
- 애플리케이션 코드, 프레임워크, 실행 명령과 의존성은 아직 정해지지 않았습니다.
- Codex Cloud에서 이 저장소를 선택하여 환경 설정을 진행할 수 있습니다. 환경 생성 성공 여부는 별도로 확인해야 합니다.

## 다음 단계

1. 만들 서비스와 기술 스택을 결정하거나 기존 프로젝트 코드를 가져옵니다.
2. 프로젝트에 맞는 설치 및 실행 명령을 추가합니다.
3. 설치와 실행을 검증한 뒤 변경 사항을 검토합니다.

## 작업 원칙

- API 키, 비밀번호와 기타 비밀 값은 저장소에 커밋하지 않습니다.
- 기존 파일을 수정하기 전에 내용을 확인합니다.
- 배포 및 외부 서비스 설정 변경은 별도로 확인합니다.
