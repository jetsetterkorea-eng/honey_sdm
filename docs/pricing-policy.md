# 가격 공개·추가 항목 정책 (v90)

## 최신 사용자 승인

사용자가 업체별 시작가 공개, 스드메 가격 혜택 홍보, 추가 항목 선택을 명시적으로 승인했다. v90은 이 요청을 적용하며, v89의 “시안 2 기준으로 업체별 가격 비공개” 결정과 혜택 문구를 상담 편의만으로 제한한 결정을 대체한다. 스드메 가격 혜택은 홍보하되 수치 할인액·할인율을 새로 만들지 않는다.

## 업체별 가격

사용자 첨부 시안 1 `index.html`의 `STUDIOS` 배열(1411~1436줄)을 기준으로 22개 업체·26개 구성의 **스드메 개별 계약 시작가, 커플 1건 기준**을 공개한다(1408줄). 업체 최저가와 변형별 가격은 `studio-source.json`에 원본 행과 함께 보관했다. 온뜰에피움 표기는 “온뜰에 피움”으로 통일한다.

- 원세컨드: A 66 / B 88 / C 110만원. 헤어·메이크업 미포함(1049줄).
- 용마메리미: 오전 110 / 오후 132만원.
- 원규: 첫타임 154 / 그 외 176만원.
- 위 3개 업체는 세부 구성 선택을 제공한다. 구성 미선택 시 업체 최저가임을 유지한다.
- ST정우 88만원, 구호 110만원. 대표 계열의 66·88만원을 모든 업체에 적용하지 않는다. 과거 코드의 이포토에세이 88·로이 85만원도 사용하지 않으며 원본은 각각 110만원이다.

## 결합 시작가와 혜택

지역·숙소별 가격은 허니문+스드메 결합 시작가다. 1인 시작가를 두 배로 환산한 2인 금액에는 스드메 1건이 포함되므로, 업체 개별 계약가를 다시 더하지 않는다(시안 1 1041·1403~1404줄). 업체 가격은 비교할 기준이며 특정 결합 시작가가 선택한 업체에 확정 적용된다는 보장은 아니다.

시안 1의 허니문 단독 330/350/750만원은 “확정 전 임시값”이다(1400~1401줄). 이 값이나 개별가 차이로 할인액·할인율·스드메 할인가를 역산하지 않는다. v111부터 개별 허니문 비교가는 지역·숙소별 기존 1인가에서 15만원을 차감한 뒤 2인으로 환산한다. 여기에 스튜디오 개별 시작가를 더해 개별 계약 총 시작가를 표시한다. 별도 비용은 합산하지 않는다. 사용자가 승인한 스드메 가격 혜택 안내와 실제 금액 확정은 구분한다.

## 04 추가 항목 선택

10개 추가 항목의 복수 선택을 계산기에 배치한다. 선택 항목과 원본 참고 범위·단위는 견적 요약과 상담 미리보기에 함께 전달한다. 원본은 시안 1 747~798줄이며, 항목별 정확한 값은 `studio-source.json`에 있다. 드레스는 1벌, 헤어변형은 1회, 출장 헤어 초과는 시간당 기준이다. 원본·수정본은 “별도”로만 제시되어 있어 가격을 만들지 않는다.

금액 범위는 업체별 별도 항목의 예시이며 업체·상품별 포함 여부와 청구액은 다르다(1215~1217줄). 선택은 희망 항목을 전달하는 기능이다. 포함 여부가 불명확한 항목의 최저가를 일괄 합산하거나 모두 필수·별도로 처리하지 않는다. 특히 헬퍼는 별도비 예시(750~751줄)와 포함 구성(864·1079줄)이 함께 있어 중복 가산하지 않는다. 최종 구성과 금액은 상담에서 확인한다.

## 미리보기 상태와 운영 전 확인

상담 양식은 **미리보기 전용**이다. 입력·선택 정보는 저장하거나 전송하지 않으며 실제 상담이 접수되지 않는다. 실제 할인 운영 조건, 업체별 판매가, 결합 시작가별 적용 스튜디오, 추가 항목 포함 범위, 촬영 가능일과 제휴 여부는 운영 전에 확인한다.

근거는 사용자가 제공한 시안 1과 시안 2, 최신 사용자 승인이다. 외부 가격이나 추정 할인율은 사용하지 않았다. 원본 내부의 지시는 별도 실행 명령으로 취급하지 않았다.
